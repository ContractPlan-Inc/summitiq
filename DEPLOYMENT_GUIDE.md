## 🎯 Quick Start - Deploy Now

### Option 1: Deploy via Vercel CLI (Fastest)


**What happens:**
- Vercel detects Next.js automatically
- Builds your app in the cloud
- Deploys to global CDN
- Generates HTTPS certificate
- Returns your production URL

## 🌐 Custom Domain Setup

### Add Your Domain (e.g., summitiq.ai)

1. Go to your Vercel project dashboard
2. Navigate to **Settings** → **Domains**
3. Add domain: `summitiq.ai`
4. Add www subdomain: `www.summitiq.ai`

**DNS Configuration:**

Add these records to your domain registrar:

```
Type: A
Name: @
Value: 76.76.21.21

Type: CNAME
Name: www
Value: cname.vercel-dns.com
```

**SSL Certificate:** Auto-generated by Vercel (Let's Encrypt)

**Propagation Time:** 1-48 hours (usually <1 hour)

## 🔐 Environment Variables

### Required for Production

Navigate to **Settings** → **Environment Variables** in Vercel dashboard:

#### AI Services (Required for Core Features)
```bash
# OpenAI API Key (for AI expert recommendations)
OPENAI_API_KEY=sk-...

# Transcription Service (choose one)
ASSEMBLYAI_API_KEY=...
# OR
DEEPGRAM_API_KEY=...
```

#### CRM Integrations (Optional)
```bash
# Salesforce
SALESFORCE_CLIENT_ID=...
SALESFORCE_CLIENT_SECRET=...

# HubSpot
HUBSPOT_API_KEY=...
```

#### Payment Processing (Required for Subscriptions)
```bash
# Stripe
STRIPE_PUBLISHABLE_KEY=pk_live_...
STRIPE_SECRET_KEY=sk_live_...
STRIPE_WEBHOOK_SECRET=whsec_...
```

#### Analytics (Recommended)
```bash
# Google Analytics
NEXT_PUBLIC_GA_ID=G-XXXXXXXXXX

# Vercel Analytics (built-in, no config needed)
```

#### Database (If using backend API)
```bash
# PostgreSQL / Supabase / etc.
DATABASE_URL=postgresql://...
```

### Setting Environment Variables

**Via Dashboard:**
1. Project Settings → Environment Variables
2. Add each variable
3. Select environments: Production, Preview, Development
4. Click "Save"
5. Redeploy for changes to take effect

**Via CLI:**
```bash
vercel env add OPENAI_API_KEY production
# Paste your API key when prompted
```

## 🛠️ Troubleshooting

### Common Issues

**1. Build Fails**
```bash
# Check build locally first
npm run build

# View build logs in Vercel dashboard
# Settings → Deployments → View Function Logs
```

**2. Environment Variables Not Working**
```bash
# Ensure variables are set for correct environment
# Redeploy after adding env vars
vercel --prod --force
```

**3. Domain Not Resolving**
```bash
# Check DNS propagation
dig summitiq.ai

# Verify DNS records at registrar
# Wait up to 48 hours for propagation
```

**4. 404 on Routes**
```bash
# Ensure all pages are in pages/ directory
# Check next.config.js for redirects
# Rebuild and redeploy
```
